Building Blocks of Neural Networks — From the Perceptron to Backpropagation

A neural network is a combination of a few building blocks: neurons that weigh their inputs, activation functions that bend the signal, hidden layers that stack up, loss functions that measure how wrong the output is, and backpropagation, which hands out blame backward to fix the weights. You will move each block yourself, and at the end you will follow the full workflow of building a real model from these blocks, evaluating it, and deploying it.

1Perceptron

The perceptron — weigh the inputs and split with a single straight line

y = step(w₁x₁ + w₂x₂ + b)Rosenblatt, 1958

In the fruit fly

When a fruit smell and a vinegar smell arrive together, a neuron receives the two signals at different strengths and adds them up. If the sum crosses the firing threshold, it sends an "approach" signal. Synaptic strength is the weight, and the firing threshold is the bias.

In a neural network

Multiply each input by its weight, add them up, and add the bias to get z. If z is 0 or more, output 1; otherwise output 0. Seen on a plane, a single straight line w₁x₁ + w₂x₂ + b = 0 separates "food" from "not food." Each time it meets a misclassified point, the perceptron moves the line a little toward that point. That is the perceptron's learning rule.

Problem

Explained for beginners

The perceptron's learning rule is one line. Pick one misclassified point and apply w ← w + η·(target − prediction)·x. If the target was 1 but it said 0, pull the line toward that point; in the opposite case, push it away. For a linearly separable problem, this rule alone will eventually get every point right.

A problem like XOR, "food only when exactly one of the two is present," cannot be split by any straight line. After Minsky and Papert proved this limitation mathematically in 1969, neural network research stalled for a while. The solution is to add one more layer: the hidden layer. But first, let's look at functions that bend smoothly instead of stepping.

2Activation functions

Activation functions — how should the signal bend?

An activation function takes the weighted sum z and decides the neuron's output a. It needs a bend for stacking layers to mean anything, and the shape of its gradient (derivative) governs how fast learning goes.

Function f(z)Gradient f′(z)Current input z
Input z

Vanishing gradients — why ReLU became the standard

Backpropagation multiplies by the activation function's gradient each time it goes back through a layer. The sigmoid's gradient is at most 0.25. Going back through 10 layers shrinks the signal to at most 0.25¹⁰ ≈ 0.00000095 times its size. Almost no "fix this" signal reaches the early layers. This is the vanishing gradient problem.

ReLU's gradient is exactly 1 in the positive range, so the signal does not shrink no matter how many layers it goes back through, and the computation is just "compare with 0," so it is fast. On the other hand, its gradient is 0 in the negative range, so a neuron that has switched off may never come back. Variants such as Leaky ReLU, ELU, and Swish try to fill this gap. No function is always the best; you choose according to the problem and the model.

3Hidden layers

Hidden layers — stacking layers only means something with an activation function

Input 2 → hidden → hidden → output 1Same data, same structure, only the activation function differs

Neurons per hidden layer

linear ∘ linear = linear

If you stack layers without an activation function, W₂(W₁x) = (W₂W₁)x, which is exactly the same as a single weight matrix. For example, if W₁ = [[1, 2], [0, 1]] and W₂ = [[2, 0], [1, 1]], then W₂W₁ = [[2, 4], [1, 3]]. Passing through the two layers or through this one matrix gives the same result. Even with 100 layers, you can only draw one straight line.

When an activation function bends the signal at every layer, straight-line pieces overlap and curve, forming a complex boundary such as a spiral. If you reduce the number of hidden neurons to 4, you can also see that there are not enough pieces to bend, so the boundary cannot wrap all the way around the spiral.

4Representation learning

Representation learning — features become more abstract layer by layer

Dots (pixels) → directions → junctions → shapes. Each layer uses the previous layer's features as material to build features one step larger.

One neuron in numbers

Weigh the 4 features from the previous layer (0.8, 0.1, 0.4, 0.0) with the weights (0.5, 0.3, 0.2, 0.1) and add a bias of 0.1.

z = 0.8×0.5 + 0.1×0.3 + 0.4×0.2 + 0.0×0.1 + 0.1
= 0.40 + 0.03 + 0.08 + 0.00 + 0.10 = 0.61
a = ReLU(0.61) = max(0, 0.61) = 0.61

Hand-designed features vs. self-learned features

The direction and junction detectors in the figure above are rules a person set in advance for the sake of explanation. Older machine learning really did have people design features this way. Deep learning learns the weights of these detectors from the data by itself. That is why it also finds features people did not think of.

What features actually form at each layer for images is covered in 3-3 (Images and CNNs).

5Loss functions

Loss functions (cost functions) — how wrong, in a single number

Learning means reducing the loss. What you choose as the loss changes what the model "fears."

Mean squared error (MSE)

(target − prediction)². The default for regression problems, where you predict a number. Used to predict continuous values such as house prices, household spending, or temperature. The backpropagation dashboard below uses this loss.

Cross-entropy

−log(probability given to the correct answer). The default for classification problems. Being confidently wrong makes the penalty grow without limit. It pairs with a sigmoid or softmax at the output.

Target
Model's predicted probability p

Why cross-entropy for classification?

With a sigmoid at the output, the MSE gradient becomes 2(p − t)·p(1 − p). If the target is 1 and the model is confidently wrong with p = 0.01, p(1 − p) is close to 0, so the gradient is almost 0 too. It is badly wrong, yet the "fix this" signal is weak. With cross-entropy, the sigmoid's derivative cancels out neatly and the gradient is simply p − t, that is, −0.99. The more wrong it is, the harder it corrects.

6Backpropagation

Gradient descent and backpropagation — guess, measure, split the blame backward, and fix

Input 2 → hidden 3 → output 1Target 1.00 · loss = (target − output)² · learning rate 0.1

01 Forward pass

First, make a guess

The input is computed along the connections all the way to the output. The first output is 0.41.

02 Loss

Measure how wrong it is

(1.00 − 0.41)² ≈ 0.35. This is the MSE from section 5 above.

03 Backpropagation

Split up the blame

Going backward from the output, compute each weight's share of the blame (its gradient).

04 Update

Fix a little at a time

New weight = old weight − learning rate × gradient. This is gradient descent.

Backpropagation is "passing on blame by multiplication"

The error amount at the output, −2 × (target − output), is determined first. The blame for a hidden→output weight is this multiplied by the signal that came in through that weight (the hidden value). An input→hidden weight goes back one more step: multiply by the output weight v to send the blame to the hidden neuron, multiply by h(1 − h) for how sensitive the hidden neuron was, and multiply by the incoming input x. This "multiply and send backward" is the chain rule. The vanishing gradients from section 2 also arise from exactly this multiplication.

Clicking "Output side only (fruit fly style)" freezes the input→hidden weights, and a teaching signal coming down from above (likened to dopamine in the fruit fly) fixes only the output-side connections. This is a heavily simplified analogy of the learning structure in the fruit fly's mushroom body, and whether the dopamine signal is computed like a gradient is still under research.

7Optimizers

Optimizers — three ways of walking down the valley

If you draw the loss as terrain, learning means walking down to find the lowest point. Even looking at the same gradient, each optimizer moves its steps differently.

SGD: one step as big as the gradientMomentum: adds the inertia it has built upAdam: adjusts the step size per direction
Learning rate η
Mini-batch noise
SGD: w ← w − η·g
Momentum: v ← 0.9·v − η·g,  w ← w + v
Adam: m ← 0.9·m + 0.1·g,  s ← 0.999·s + 0.001·g²,  w ← w − η·m̂ / (√ŝ + ε)  (m̂ and ŝ are bias-corrected for the initial values)

Explained for beginners

This valley is long horizontally and steep vertically. SGD moves only as much as the gradient, so in the steep vertical direction it bounces up and down with big steps (zigzag), and with a small learning rate it crawls along the gentle horizontal direction (check this with "0.1 Small"). Momentum remembers the speed it has built up, so it accelerates in the consistent direction (horizontal) while the zigzags cancel each other out. Adam measures the gradient size separately for each direction and adjusts the step size, so it descends horizontally and vertically at a similar pace.

"Mini-batch noise" is the jitter that comes from computing the gradient on only part of the data, as in real training. Set the learning rate to "Large" and SGD bounces over the valley walls. No optimizer always wins. Adam is widely used because it is a safe default for most problems, but there is also research showing that well-tuned SGD generalized better to unseen data on several deep learning tasks [R12].

8Overfitting

Overfitting and regularization — memorizing vs. understanding

Dropout
Weight decay (L2)
Early stopping

Three remedies

  1. Early stopping: Use the model from the point where validation loss was lowest. It is the simplest and is used almost always.
  2. Dropout: During each training step, randomly switch off some hidden neurons. This stops the network from memorizing points by relying on a few specific neurons. At test time, all neurons are switched on.
  3. Weight decay (L2): Add a penalty to the loss that grows as the weights grow. This keeps the curve from becoming too wiggly.

The surest remedy is to collect more data. With little data and a big model, memorizing is easy. The numbers in this figure come from an illustrative experiment computed directly on this page, and the random seed is fixed so that it gives the same result every time it runs.

9Full workflow

The full model-building workflow — from data to deployment

All the blocks we have seen so far fit into a single step: training. In real work, what comes before and after is longer. The example is a "find the defects" model for a factory inspection station.

① Collect→ ② Split→ ③ Preprocess→ ④ Train→ ⑤ Evaluate→ ⑥ Save · deploy→ ⑦ Monitor

⑤ Evaluate — accuracy alone will fool you

Of 200 inspected products, 20 are actually defective. The model outputs a "probability of being defective" for each product. Try changing the cutoff above which a product is judged defective (the threshold).

Defect threshold

Common mistakes at each stage

  1. Split: Use the test data only once, at the very end. Choose settings with the validation data, and measure final performance with the test data. For data with a time order, do not shuffle randomly; train on the past and evaluate on the future (more in 3-6).
  2. Preprocess: Compute scaling references (standardization) such as the mean and standard deviation from the training data only. Computing them on all the data lets test information leak in (data leakage).
  3. Evaluate: If only 10% are defective, just saying "all normal" gives 90% accuracy. Look at the side you must not miss (recall) together with the cost of false alarms (precision).
  4. Deploy · monitor: When the factory lighting changes or new parts come in, the data changes and performance drops. Keep measuring performance after deployment, and retrain when needed.

Check questions (click to expand the explanation)

Q1. If you stack 10 hidden layers in a neural network without activation functions, what kind of boundary can it draw?

Only a single straight line (a plane in higher dimensions). Combining linear transformations many times still gives a single linear transformation (W₂W₁x = Wx). The left figure in section 3 is an example.

Q2. Why does using ReLU instead of the sigmoid reduce vanishing gradients?

The sigmoid's gradient is at most 0.25, so it shrinks quickly as it is multiplied at each layer. ReLU's gradient is 1 in the positive range, so it does not shrink going backward. However, it is 0 in the negative range, so dead neurons can appear.

Q3. When the target is 1 and the prediction is 0.41, what are the MSE loss and ∂L/∂y?

L = (1 − 0.41)² = 0.3481 ≈ 0.35. ∂L/∂y = −2 × (1 − 0.41) = −1.18. These match the first-round values in the section 6 dashboard.

Q4. Training loss keeps decreasing, but validation loss starts rising at some point. What is happening, and what should you do?

It is overfitting. Use the model from the point where validation loss was lowest (early stopping), turn on dropout or weight decay, or add more data.

Q5. In an inspection with a 10% defect rate, what are the accuracy and recall of a model that answers "all normal"?

Accuracy 90%, recall 0%. It found no defects at all. That is why you must not look at accuracy alone on imbalanced data.
